# Полировка Mini App (после онбординга)

Цель: остальные экраны должны быть на уровне онбординга. Живые, но спокойные анимации,
понятные цифры, никакого «красного стыда», одинаковые компоненты везде.

Принципы те же, что в ONBOARDING.md: анимируем только transform/opacity, 180–450 мс,
`prefers-reduced-motion` — всё мгновенно; мягкий тон.

## 0. Фундамент (css/app.css, ui.js, main.js)

1. Поднять `--ease-spring: cubic-bezier(.2,.9,.3,1.2)` и `--ease: cubic-bezier(.4,0,.2,1)` в `:root`
   (onb-переменные ссылаются на них). Использовать `--r-card`/`--r-ctl` вместо литералов 11px/20px.
2. Убрать дубль тёмной палитры (одна копия + селекторы через запятую), дубли `.toast`,
   `.seg button.active`, `.add-hero-pic`, `.list.tiles/.thumbs`. Удалить мёртвые селекторы
   (.kcal-left, .kcal-info, .seg-in, .row-btns, .card-title.with-ico, .thumb-photo) если
   действительно не используются.
3. Появление контента: после загрузки экрана карточки `.card`/`.list` верхнего уровня
   въезжают по очереди (opacity 0→1, translateY 8px→0, stagger 40 мс, максимум 8 элементов).
   Класс `.stagger` на `.screen`, задержки через `--i`.
4. Новый хелпер `countUp(el, to, {ms=700, fmt})` в ui.js (requestAnimationFrame, easeOutCubic,
   reduced-motion → сразу финал). Использовать для крупных чисел.
5. Нажатия: у всех кликабельных карточек/строк/чипов `:active { transform: scale(.98) }`
   с transition 120 мс (где ещё нет).
6. Хаптика: `haptic('selection')` при смене таба и в любом `segmented()` (внутри хелпера, один раз).
7. Общие компоненты вместо копий:
   - `dateSwitch(date, onChange)` в ui.js — заменить копии в today.js и analysis.js.
   - `macroChips({p,f,c})` в ui.js — заменить копии в products.js, favorites.js, profile.js, meal.js.
   - weekgoal.js `days()` → `plural()` из ui.js.
8. Цветовые литералы в JS (today.js '#af52de', stats.js '#30b0c7', TILE) → CSS-переменные.

## 1. Сегодня

1. **Кольцо.** Сейчас три кольца — углеводы/белки/жиры, а калории только числом в центре:
   непонятно, сколько съедено от нормы. Делаем одно крупное кольцо калорий (толстое,
   градиент `--c-green`→бирюзовый; при перерасходе дуга сверх 100 % — мягкий `--c-warn`,
   не красный). Дуга анимируется от 0 при первом показе дня (ring-in уже есть), число
   «осталось» — countUp. При перерасходе центр: «сверх нормы» + число.
2. Под кольцом три колонки БЖУ остаются, но под каждой — тонкая полоска прогресса
   (4px, цвет макроса, заполняется с анимацией scaleX, stagger).
3. **Частые блюда** («Овсянка с бананом +1 410») — сейчас переносятся на 3 строки и «+1» непонятно.
   Один горизонтальный скролл-ряд (scroll-snap, без скроллбара, края с fade-маской),
   чип: мини-картинка блюда (pics) + название + «410 ккал» мелко серым. «+1» убрать
   (если позиций несколько — название первой + « и ещё 1»). Перенести блок ПОД список
   приёмов, с заголовком «Повторить».
4. Плитки сон/шаги/вес: показывать «+ добавить» серым, если значения нет; у веса — маленькая
   стрелка тренда (↓ зелёная / ↑ серая), если есть вчерашний/предыдущий вес в ответе /day
   (если данных нет — не показывать, бэкенд не трогать).
5. Свайп влево/вправо по шапке-дате переключает день (только горизонтальный жест > 60px,
   не мешает вертикальному скроллу). Контент дня при смене — короткий slide 12px + fade.

## 2. Статистика

1. **Дельта-чипы без красного.** Красный «−515» у калорий при похудении — это хорошо, а выглядит
   как ошибка. Правило: зелёный — движение в сторону цели, серый — нейтрально/хуже. Никогда
   не красный. Калории: ниже нормы, но ≥ 80 % → зелёный «в дефиците»; ниже 80 % → серый
   «маловато»; выше нормы → серый. У «Дней в норме» чип убрать (−11 ничего не значит).
2. Плитка «Вес (тренд)»: добавить мини-спарклайн тренда (SVG, 40px высотой) и строку
   «до цели N кг», если goal_weight есть в ответе или в api.me().
3. Подписи целевой линии («цель 7 ч», «норма 1 650») сейчас наезжают на столбики — выносить
   над графиком справа (в строку заголовка карточки, серым) и убрать с линии.
4. Столбики калорий красить по статусу: в коридоре 80–120 % — `--c-green`, ниже — `--c-fill`
   полупрозрачный зелёный, выше — `--c-warn`. Легенда под графиком.
5. Анимация графиков: столбики растут снизу (scaleY, transform-origin bottom, stagger 10 мс),
   линия веса рисуется stroke-dashoffset 600 мс. Только при первом показе диапазона.
6. Haptic selection на переключении диапазона (через segmented).
