# Статистика и Анализ: редизайн

Проблема: оба раздела — стопка одинаковых белых карточек с текстом и шесть похожих
бар-чартов. Нет главного визуала, нет картинок и цвета, разделы дублируют друг друга
(график веса, показатели, выводы есть в обоих).

Разводим роли:
- **Статистика = «как я иду»**: цифры и картинки прогресса, минимум текста.
- **Анализ = «тренер»**: вердикт, что получилось, одно главное действие, советы.

Стиль как у онбординга и «Сегодня»: один крупный «герой» сверху, цвет и градиенты,
countUp на числах, появление со stagger, анимации только transform/opacity, reduced-motion.
Никакого красного.

## Статистика

Порядок сверху вниз (под сегментом Неделя / Месяц / 90 дней):

1. **Герой «Вес».** Карточка `--r-card-lg` с лёгким градиентом-подложкой (как кольцо на Сегодня).
   - Слева сверху мелко «Вес по тренду», крупно текущий трендовый вес (countUp, 40px, tabular-nums),
     справа чип «−2,0 кг за месяц» (зелёный, если вниз при цели похудеть, иначе серый).
   - График: линия тренда толщиной 3px + **заливка градиентом** под ней (accent 25 % → 0 %),
     точки взвешиваний мелкие полупрозрачные, текущая точка с пульсирующим ореолом,
     пунктир цели с подписью «цель 76» у правого края, если цель попадает в диапазон оси
     (иначе подпись цели в шапке). Минимум сетки: 3 горизонтальные линии, без вертикалей.
   - Касание/ведение пальцем по графику — вертикальный маркер + тултип «12 окт · 83,4 кг».
   - Под графиком: полоска прогресса старт → цель (как в Меню) и строка
     «до цели 6,6 кг · в этом темпе ≈ к 14 января» (если темп отрицательный и цель ниже;
     иначе без даты). Данные: stats + api.me() (goal_weight, стартовый вес если есть).
   - Анимация: линия рисуется stroke-dashoffset, заливка fade-in после.
2. **«Дни в норме» — календарь-хитмап.** Сетка по неделям (7 колонок Пн…Вс, подписи дней
   сверху мелко), ячейка = день, скругление 6px:
   в коридоре 80–120 % — `--c-green`; ниже — зелёный 35 %; выше — `--c-warn` 70 %;
   нет записей — `--c-fill`; будущие дни пустые; сегодня — обводка.
   Для 90 дней ячейки меньше (gap 3px), для недели — одна строка крупных ячеек с ккал внутри.
   Шапка: «16 из 30 дней в норме» крупно + справа чип с иконкой flame «серия 4 дня»
   (текущая серия подряд в коридоре; если 0 — не показывать). Легенда-точки снизу.
   Ячейки появляются волной (stagger по диагонали, 8 мс). Тап по ячейке — тултип с датой и ккал.
3. **Показатели 2×3.** Плитки одинаковой высоты: цветная иконка-плитка (как в листе «+»),
   название, крупное значение, под ним маленькое кольцо или полоска «% от цели» и чип
   изменения к прошлому периоду (зелёный/серый). Набор: Калории (ср.), Белок (ср.), Вода (ср.),
   Сон (ср.), Шаги (ср.), Дни с записями. Плитки «Вес» и «Дни в норме» убрать — они в 1 и 2.
4. **«Динамика» — один график с переключателем.** Чипы-переключатель (горизонтальный скролл):
   Калории · БЖУ · Вода · Сон · Шаги. Смена — crossfade 200 мс + рост столбиков заново.
   Столбики со **скруглёнными верхами** (rx 3), цель — пунктир, подпись цели в шапке карточки
   справа («норма 1 650»), для калорий цвета по статусу как в хитмапе, для БЖУ стек.
   Тап по столбику — тултип. Подпись-итог под графиком одной строкой (как сейчас).
   Выбор метрики помнить в localStorage `stats_metric`.
5. **Ссылка на Анализ** вместо блока «Что видно»: тонированная карточка с иконкой sparkles,
   «Разбор и советы за месяц», подзаголовок — первая строка из текущего «Что видно»
   (сокращённо), стрелка. Ведёт на #/analysis с соответствующим периодом
   (неделя → week, месяц и 90 дней → month).

## Анализ

### День
1. **Герой-вердикт.** Карточка с мягким градиентом по вердикту:
   хорошо — зелёный, нормально — жёлтый/янтарный, есть что поправить — персиковый (не красный).
   Слева кольцо-оценка 84px (countUp процента), справа заголовок (22px bold) и подзаголовок,
   **3D-картинка** из `img/onb/` в правом верхнем углу 56px с лёгким наклоном
   (хорошо → `party`, нормально → `heart_check`, поправить → `salad`). Чипы статуса под текстом.
2. **Показатели с полосками.** Каждая строка: иконка, название, справа «1 580 / 1 650 ккал»;
   под строкой полоска прогресса значение/цель (цвет по статусу: в норме зелёный,
   почти — жёлтый, поправить — `--c-warn`; перебор показывать как полную полоску +
   оранжевый хвост). Полоски заполняются со stagger.
3. **Что получилось** — компактно: зелёные пилюли с галочкой в строку с переносом (flex-wrap),
   а не список строк.
4. **Главное на завтра** — первый совет из «Что поправить» показывать оранжевой
   градиентной карточкой как «Главное на следующую неделю» в недельном виде
   (тот же компонент). Остальные советы — обычные карточки с иконкой-плиткой.
5. Цель на неделю — как есть.

### Неделя / Месяц
1. Тот же герой-вердикт (картинка по вердикту).
2. «Главное на следующую неделю» — оставить (это лучшая карточка раздела).
3. **Показатели — сетка 2×N плиток** вместо длинного списка: иконка, значение, полоска к цели,
   чип «к прошлому», строка-подпись мелко («в норме 5 из 6 дн.»).
4. **Вес** — убрать полный график (он в Статистике). Компактная карточка: «−0,7 кг»,
   мини-спарклайн 48px, «до цели 9,3 кг, при таком темпе ≈ 19 нед.», ссылка «График →»
   на #/stats.
5. Что получилось — пилюли как в дне. Закономерности и советы — карточки с иконкой-плиткой;
   у закономерностей вместо синей полоски слева — иконка + тонированный фон `--c-tonal`.

## Общие компоненты (ui.js / charts.js)

- `heroCard({tone, children})` с тонами green / amber / peach / accent.
- `progressBar(value, target, {status})` — одна реализация для Анализа, Меню, Статистики.
- `statTile({icon, color, title, value, pct, delta, caption})`.
- В charts.js: area-fill градиент (уникальный id на SVG), скруглённые столбики,
  интерактивный тултип (pointer events, работает пальцем), пульс текущей точки,
  меньше сетки. Тултип — плашка `--c-card` с тенью, скрывается по отпусканию/тапу вне.
