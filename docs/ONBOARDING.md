# Онбординг первого запуска (Mini App)

Сейчас: `/start` в чате задаёт 8 текстовых вопросов, а Mini App до этого отвечает 409
«Сначала пройдите настройку». Человек видит стену текста и не понимает, зачем всё это.

Цель: за ~60 секунд показать, чем бот поможет, и собрать всё, что нужно для расчёта,
одним касанием на вопрос. Онбординг живёт в Mini App, чат остаётся запасным путём.

## Принципы

1. **Сначала выгода, потом вопросы.** Три экрана «что я умею» с живыми анимациями,
   потом вопросы. Пропустить можно сразу («Пропустить» вверху).
2. **Один вопрос — один экран.** Крупные карточки и линейки вместо полей ввода.
   Клавиатура не появляется ни разу.
3. **Прогресс виден.** Тонкая полоса сверху, растёт плавно. Назад — кнопка Telegram BackButton.
4. **Каждый ответ сразу что-то показывает.** Ввёл рост и вес — видишь ИМТ;
   выбрал цель — видишь «−8 кг»; выбрал темп — видишь дату. Это и есть мотивация.
5. **Мягкий тон, без стыда.** Никаких «лишний вес», «ожирение», красного цвета на ИМТ.
   Формулировки как в остальном боте: «вы», спокойно, коротко.
6. **Безопасность из текущего онбординга сохраняется:** 18+, цель не ниже ИМТ 18,5,
   при ИМТ < 18,5 дефицит не включается, предупреждение для беременных/диабета/РПП,
   осторожный режим (care_mode) предлагается прямо в онбординге.
7. **Анимации:** только `transform`/`opacity`, 200–450 мс, пружинный easing
   `cubic-bezier(.2,.9,.3,1.2)` для появления, `cubic-bezier(.4,0,.2,1)` для переходов.
   `prefers-reduced-motion` — всё мгновенно, счётчики сразу финальные.
   Хаптика Telegram: `selectionChanged` на каждом делении линейки, `impactOccurred('light')`
   на выборе карточки, `notificationOccurred('success')` на финале.

## Поток экранов

```
Intro (3 слайда, свайп)  →  Вопросы (9 экранов)  →  Расчёт  →  Результат  →  Сегодня + подсказка
```

Часовой пояс не спрашиваем: `Intl.DateTimeFormat().resolvedOptions().timeZone`, правится в профиле.
Имя берём из Telegram (`first_name`) и обращаемся в заголовках intro: «Привет, Аня!».

### Часть 3. Расчёт (1,8 с, честно — запрос идёт параллельно)

Экран «Считаю вашу норму»: три строки появляются по очереди с галочкой
(«Обмен веществ по формуле IOM», «Поправка на активность», «Безопасный темп»). Кольцо
крутится вокруг иконки. Экран держится max(ответ сервера, 1,8 с). Ошибка — тост и возврат к Q11.

### Часть 4. Результат

- Конфетти-взрыв из 24 частиц (CSS, один раз) + `notificationOccurred('success')`.
- «Ваша норма» — число ккал считается 0 → N за 900 мс.
- Три полоски БЖУ заполняются по очереди, ниже вода в мл.
- Мини-график: прямая от текущего веса к цели с подписью даты (или «Держим вес»).
- Заметки безопасности (если сервер вернул `notes`: ИМТ < 18,5, поднят до минимума).
- Мелко: «Это не медицинский сервис, оценки приблизительные. Если вы беременны, кормите
  грудью, есть диабет или РПП — обсудите похудение с врачом».
- CTA (MainButton): «Начать». В care-режиме вместо ккал — «Норма рассчитана, цифры спрячу».

### Часть 5. После онбординга

Переход на `/today`, один раз показывается подсказка-пузырь над «+»: «Начните с первого
приёма пищи — сфотографируйте или опишите словами» (пульсирующее кольцо вокруг кнопки,
закрывается тапом, флаг в localStorage `onb_hint_done`). Бот одновременно пишет в чат
короткое сообщение «Профиль готов, норма ≈1900 ккал. Кидайте еду сюда текстом, фото или голосом».

## Вход в онбординг

- `/start` для нового человека: короткое приветствие из 2 строк + inline-кнопка WebApp
  «✨ Настроить за минуту» (`WEBAPP_URL`). Под ней обычная кнопка «Ответить в чате» —
  запускает старый текстовый поток (и он же используется, если `WEBAPP_URL` не задан).
- Mini App: `GET /api/me` для неонбординговых возвращает `{"onboarded": false, first_name}`
  вместо 409; фронт показывает онбординг вместо табов. Остальные `/api/*` по-прежнему 409.
- Состояние онбординга хранится в `sessionStorage` — закрыл и открыл, продолжаешь с того же шага.

## API

`POST /api/onboarding` — разрешён без `onboarded`. Тело:

```json
{"sex": "female", "birth_year": 1991, "height_cm": 168, "weight_kg": 82.4,
 "goal_weight_kg": 72, "rate_kg_week": 0.5, "activity": 2, "eating_cutoff": "21:00",
 "tz": "Europe/Minsk", "care_mode": false, "goal": "lose",
 "reminders": {"morning": true, "evening": true, "water": true, "weigh": true, "weekly": true}}
```

Ответ: `{"profile": …, "targets": …, "notes": ["…"], "goal_date": "2027-03-14"|null}`.
Логика — общая с чатом: `_finish` из `routers/onboarding.py` выносится в
`services/onboarding.py::complete(db, tg_id, data)`, чат и API зовут одно и то же
(валидация границ, 18+, ИМТ, цель ≥ ИМТ 18,5, напоминания, стартовый вес в журнал веса).
Повторный вызов для уже онбординговых — 409 `already_onboarded`.

## Картинки

Лист в стиле существующих (3D Apple-emoji, пурпурный фон, `tools/slice_sheet.py`),
папка `img/onb/`, размер 192×192 (на экране до 96 css px):
camera_plate, night_tea, chart_down, scale, heart_check, salad, male, female, sofa, sneaker,
bike, dumbbell, turtle, target, rabbit, fridge_lock, alarm, party.

## Что не делаем

- Не спрашиваем талию/бёдра и Mi Band (решение пользователя ранее).
- Не делаем регистрацию/логин — всё через Telegram initData.
- Не делаем платный экран/пейволл.
