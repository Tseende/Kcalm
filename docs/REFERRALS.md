# Приглашения и заморозки — этап 1

Вход: Mini App → Меню → Пригласить друга, либо `/invite` в чате.
Каждый пользователь с завершённым профилем получает 3 приглашения.
Ссылка `https://t.me/<bot>?start=r_<code>` открывает доступ новому человеку,
списывая одно приглашение. Повторное открытие не списывает его снова.
Mini App также принимает код в подписанном Telegram `start_param`
(ссылка приложения с `startapp=r_<code>`); неподписанные параметры URL доступа не дают.

После настройки друг получает одну заморозку. За записи еды в 3 разных дня
первой недели пригласивший получает одну заморозку и одно приглашение.
Неделя — 7 календарных дней в часовом поясе друга, включая день настройки.
Будущие даты и активация после окончания недели не учитываются.
Награды выдаются максимум за 10 активированных друзей. Повторное сохранение
еды и повторный онбординг не дублируют награды.

При записи еды за сегодня заморозка автоматически закрывает вчерашний пропуск,
если позавчера была запись. Два последовательных пропуска серию прерывают.
Все начисления и расходы заморозок сохраняются в `reward_log`.
В списке друзей видны только имя и этап активации, без веса и калорий.

Миграция `031_referrals.sql` применяется стандартным механизмом при запуске.
`app.bot.main` подключает обработчик сохранения еды и уведомления Telegram.
В отдельном процессе, использующем только API, нужно также вызвать
`referral.install(...)` для наград при записи еды.

Проверка: `python -m pytest tests/test_referral.py tests/test_referral_api.py -q`.
Для ручной проверки нужны два Telegram-аккаунта: настроенный пригласивший
и новый пользователь вне ALLOWED_TG_IDS. Реальная отправка сообщений и
переход между Telegram и приложением проверяются после запуска бота.
