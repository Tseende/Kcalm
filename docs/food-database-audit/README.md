## Что улучшать сначала

1. Исключить совпадения коротких названий внутри чужих слов и усилить проверку релевантности.
2. Добавить отсутствующие частые продукты, варианты приготовления и сырой/готовый вес.
3. Для упакованных продуктов брать значения с этикетки/штрихкода, не размножать приблизительные бренды.
4. Проверять качество уже имеющихся значений и показывать источник оценки.

База небольшая для разнообразного питания, но количество записей само по себе точность не гарантирует.
Четыре записи с расхождением энергии и формулы 4/9/4 отмечены для проверки; для алкоголя
расхождение ожидаемо, так как формула не учитывает энергию спирта. Это не доказательство неверных КБЖУ.
Код расчёта, подбор и действующая БД в ходе аудита не изменялись.
